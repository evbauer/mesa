# Same-query native refinement control

Table-only archived-field fidelity sidecar. No source solver, table/cache
generation, core/runtime/default change, or independent source-accuracy claim.
All grids predict **the same printed native reference fields at the same
individual targets**, not targets generated by each interpolator.

## Reproduce

```sh
python3 -B mesa/eos/eosFreeEOS_builder/biquintic/refinement_control/test_refinement.py
python3 -B mesa/eos/eosFreeEOS_builder/biquintic/refinement_control/run_control.py --overwrite
```

Uses existing NumPy/SciPy/Matplotlib; no install/build. `-B` avoids bytecode
writes into imported worker directories. The runner pins table SHA-256 to
`e6ca7ce27bee8197bb257a8c4886a06366e6951e58958fbed3735c877ee68502`.
Evaluator and region-definition hashes are recorded. All outputs go to
`freeeos_biquintic_progress/experiments/021_refinement_control/`:
`README.md`, `SUMMARY.md`, `results.json`, `error_summary.csv`,
`paired_queries.npz`, one `paired_refinement.png`, test log, and private
Matplotlib configuration/cache. Existing products require `--overwrite`.

## Nested grids and leakage prevention

Retained original grid indices are `0,stride,2*stride,...`, with strides
**2, 4, 8** and a shared anchor. Both original target indices are **odd**,
so no target is retained on any measured grid or lies on a coarse grid face.
Stride 1 retains every original source-node target: its nodal reproduction
cannot be labeled a holdout result and is excluded from measured refinement
ratios. The original stride-1 table supplies the single printed reference only.

Per retained grid, reconstruct low constraints from **coarse rows only** and
estimate all missing twists anew using radius-2 mean routes. No derivatives
estimated from fine/withheld rows are reused. Original validity metadata can
inspect flags, finiteness, and coordinates; it is not a fitted constraint.
The analytic test deliberately corrupts withheld E/Cv and verifies unchanged
retained rows and BQ nodal arrays at every stride.

Candidates:

- `BQ_total`: one biquintic total potential using retained constraints.
- `BQ_split`: coherent current-CRAD analytic reference subtraction/restoration.
- `NAK4_columns`: separate raw log/response-column fits on four retained nodes
  per axis. With four nodes, a not-a-knot spline equals a cubic polynomial;
  the tensor Lagrange implementation is tested against SciPy CubicSpline.
  Every 4x4 window donor is native/valid. This is a **local synthetic bicubic
  column control**, not a globally fitted spline, a thermodynamically consistent
  potential, or an executed MESA cache. Adjacent local windows need not share
  derivative continuity. No global fallback contamination is introduced.

The optional C3 candidate is omitted from this bounded primary comparison;
there is no C3-versus-BQ claim using a different sample.

## One common domain

Require native finite positive-response reference rows, logT>=3.2, audited
header-coordinate agreement within 1e-10 dex, and iq520 exclusion. Derivative/
column-window donors must all be native and clear of exclusions. Target and
containing coarse-cell corner masks require current Prad/Pgas<1e-3, -8<=q<=5,
logT<=7.8, plus the declared table own-use condition. Donors are not claimed
to belong to an active MESA component blend.

Of **6,167** eligible odd/odd reference rows, BQ validity at strides 2/4/8
accepts 5,672/5,264/3,456; NAK4 accepts 5,837/5,588/4,784. Intersect all nine
candidate/grid masks **before any error comparison**: **3,456 common targets**.
All are used with the default 4,000-query cap; if capped, one deterministic
sample is selected once and reused everywhere. No resolution-dependent
sample-set change is allowed. Per-candidate coverage remains reported separately.

Region bins copy the actual q/T rectangles from experiment 015, not new physics
fits. Counts on this common set: H-ionization geometry 42, helium-ionization
192, dense-tail 68, active-chiT geometry 126, and added logT>=7 geometry 1,072.
Bins may overlap. `active_chiT` is a patch name, **not** a measured FreeEOS
fraction. Sparse or absent bins do not justify extrapolated region conclusions.

## Results and interpretation

Native reference decoding: base-10 Pgas/E/S logs; total Cv/Cp/chiRho/chiT
columns. BQ reconstructs total pressure with declared current MESA CRAD and
returns Pgas with that convention. Printed energy/entropy gauges are preserved;
no gauge or radiation constant is fitted away.

For `BQ_split`, p99 relative archived-field errors on the identical sample:

| Field | stride 8 | stride 4 | stride 2 |
| --- | ---: | ---: | ---: |
| Pgas | 8.78e-4 | 2.30e-5 | 4.15e-6 |
| E | 7.09e-4 | 5.19e-5 | 2.18e-6 |
| S | 1.77e-4 | 1.27e-5 | 7.16e-7 |
| Cv | 1.48e-2 | 1.57e-3 | 4.39e-4 |
| chiRho | 8.69e-3 | 1.74e-3 | 4.16e-5 |
| chiT | 1.35e-2 | 1.94e-3 | 2.14e-4 |

Maxima, Cp errors, per-region errors and all controls appear in JSON/CSV.
No candidate produces nonfinite/nonpositive fields or chi responses on this
common screened set. That is not a positivity claim over all cells/interiors.

Individual errors need not decrease monotonically. For BQ split, Cv improves
at 93.7% of targets for 8→4 and 92.2% for 4→2; chiRho improves at 89.0% and
96.0%. Median individual coarse/fine error ratios are respectively 15.0/10.6
for Cv and 6.31/53.7 for chiRho. Large ratios can reflect a nearly vanishing
fine error and **must not be converted into a claimed convergence order**.
Zero denominators/nonfinite pairs are counted explicitly, never regularized
silently. Raw per-point errors and ratios are preserved in the NPZ.

Dense-tail Cv p99 decreases more slowly: 5.83e-3→3.43e-3→2.08e-3.
Total versus split BQ is nearly identical on this material subset, and neither
is guaranteed better at every point. NAK4 has larger aggregate errors here;
this does not establish accuracy of MESA's actual cache/interpolation route.

The paired plot shows the same individual Cv/chiRho errors at successive meshes,
with the equality diagonal. Its 1e-16 display floor is **not** used in error
or ratio calculations. Four tests pass: same never-retained targets with smooth
full-pipeline Cv improvement, no withheld-constraint leakage, four-node NAK
equivalence, and zero-ratio accounting. These verify the sidecar, not fresh
FreeEOS source accuracy or formal production-grid convergence order.
